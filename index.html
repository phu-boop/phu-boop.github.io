PROJECT // 02 1M+ ROWS BENCHMARK

Personal Expense Management — Financial Engine

PROBLEM

Financial tracking applications must guarantee exact account balances under rapid parallel mutations and prevent catastrophic memory exhaustion when exporting million-row datasets into structured documents.

ARCHITECTURE

Built on a strict Layered Architecture (Controller → Validator → Service → Repository → Worker). Transactions act as the immutable source of truth, updated atomically using MongoDB Decimal128 and decimal.js for floating-point safety. Implemented wallet versioning and an optimistic concurrency retry mechanism (MAX_TRANSACTION_RETRIES = 3) to eliminate race conditions.

RESULT

Engineered a Redis-backed background worker pipeline capable of streaming 1,062,516 rows across 426 chunks into a 27,626-page PDF (~71 MB) while keeping memory bounded at a peak RSS of ~590 MB without worker death.
